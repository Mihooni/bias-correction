# Bias Correction（认知偏误纠正系统）

> 不告诉你"你错了"——而是问"有没有可能……"。一个让 AI 自动检测并温和纠正 39 种认知偏误的 skill。

**简体中文** | [English](README.en.md)

**版本**：v1.1.0 | **更新**：2026-09-09 | **许可证**：MIT

## 这是什么

一个触发词驱动的认知偏误纠正 skill。当你的提问出现偏误信号（过度确定、直觉先行、从众、沉没成本……）或隐式推理结构（单向因果链、滑坡论证、幸存者案例……）时，AI 会自动介入，指出推理在哪里出了问题，并给出可执行的纠正动作。

**不是**：所有问题都强制过一遍偏误检查清单。
**而是**：平时正常回答，只在检测到偏误信号时才介入，且介入强度随问题深度自动调节。

## 谁需要它

| 你是 | 你会遇到 | 这个 skill 帮你 |
|---|---|---|
| **普通用户** | "再坚持一下应该就行""大家都这么说肯定没错""我就是感觉不对"——这些话一出口，决策已经开始跑偏 | 在你*说出口的瞬间*识别偏误信号，用"有没有可能……"温和点破，不指责、不说教 |
| **互联网精英** | 投资加仓止损、数据解读、竞品判断、团队归因——每个偏误都直接挂钩真金白银 | 沉没成本/过度自信/幸存者偏差/基础概率忽视……39 个偏误按场景匹配，深度分析后记入决策日志、30 天复盘验证 |
| **AI 创作者 / 开发者** | 你的 agent 会顺着用户的话走，用户错它跟着错 | 给 agent 装上"防错护栏"：双通道触发识别 + 第一性原理前置 + 元层自检（防纠偏本身变成偏差），即插即用 |

## 对比效果：装 vs 不装

| 维度 | 普通 AI 对话 | 装上 bias-correction |
|---|---|---|
| 你说"我都投了20万了" | 顺着帮你分析"怎么坚持下去" | 点破：这是沉没成本谬误，真正的检验是"今天第一次接触还会投吗" |
| 识别方式 | 你主动说"帮我客观分析"才有效 | 触发词驱动：你一出现偏误信号就自动介入，无需自觉 |
| 纠偏方式 | 直接说"你错了"，令人防御 | "有没有可能……"——温和、对事不对人 |
| 纠偏质量 | 换个说法重复你的观点 | 强制含"谁做/怎么验证/失败信号"三件套 + 至少一个隐式偏差 |
| 自我检查 | 无 | 元层防护：纠偏建议本身也要过偏误检查 |
| 长期 | 复盘靠回忆，越想越对 | 决策日志白纸黑字，30 天后拿真实结果对账 |

## 核心能力

- **39 个认知偏误**：8 个必学 + 31 个进阶，覆盖信息处理/自我认知/社会群体/决策行为/概率预测五大类
- **双通道识别**：显性触发词（"我肯定""大家都这样""已经投了"）+ 8 类隐式推理结构（果→因单向链、极端类比、虚假均势……）
- **分级介入**：L0/L1 轻度点缀，L2-L3 才激活完整六步协议——不在小事上舞大刀
- **第一性原理前置**：纠偏之前先拆解底层事实，防止"纠偏本身变成另一种偏差"
- **默会知识激活**：尊重经验直觉，逻辑与直觉矛盾时明确标注取舍
- **对抗性审查**：输出前红队自己的结论——最强反对者/压力测试/代价不对称
- **决策追踪**：深度分析后生成决策日志，30 天后提醒复盘，用真实结果校准判断
- **文化适配**：参考父母/面子/集体优先等东方情境不误诊为偏差
- **元层防护**："我已经懂偏误所以免疫"本身就是偏差（道德许可），系统自带自检

## 你会得到什么变化

不吹数字，只讲机制——每一项都可以用一次对话验证：

- **抓住自己看不见的错**：确认偏误、幸存者偏差、动机性推理的共同点是"身在其中毫无感觉"——触发词 + 8 类隐式推理结构双通道识别，专抓这类盲区
- **纠偏不伤感情**：所有纠正用"有没有可能……"句式，对事不对人，伴侣/同事/团队讨论中也适用
- **建议能落地**：每条纠正含"谁做/怎么验证/失败信号"三件套，不是"要客观"这种空话
- **判断力复利**：决策日志 + 30 天复盘，每一次深度分析都变成校准未来判断的数据点

## 输出示例

### L0 简单问题（轻介入，不展示框架）

**问**："Python 最新版本是多少？"

**答**：Python 3.12.4。

> 注意一个常见误区：直接照搬官网首页版本号——某些发行版/框架有各自的支持矩阵。

### L2 深度问题（完整协议，输出偏差本质）

**问**："我在这个项目已经投了 20 万，虽然数据一直不好，但再坚持半年应该能行吧？"

**答**：

## 偏差本质
你的推理核心是 **沉没成本谬误（BC#29）+ 确认偏误（BC#1）**——用"已投入"支撑"继续投"，再用"应该能行"回避了反面证据的主动搜寻。

## 分析
关键检验不是"还能不能坚持"，而是**"今天是第一次接触，看到这个项目的现状，我还会投 20 万进去吗？"**——把过去的投入从决策里完全剥离后，剩下的才是真判断。隐式偏差：你说"应该能行"时依据的是希望而非数据，这是**动机性推理（BC#14）**——结论先于证据链。反直觉一点：此刻止损不是承认失败，而是把剩余资源从"补过去的洞"挪到"赌未来的赢"，两者期望值完全不同。

## 行动
1. **今日重判** — 假装第一次评估这个项目，只看现有数据决定投不投 — 今天
2. **设定验证点** — 写下"3 个月内出现什么信号就该撤"，白纸黑字 — 本周
3. **算机会成本** — 这半年时间和预算如果投到第二选择，期望回报是多少 — 1 周内

## 不纠的代价
最常见的结局不是"坚持成功了"，而是 6 个月后再投 20 万，用更大的沉没成本支撑更难回头的处境。

## 适用场景

### ✅ 适合触发
- 投资决策（加仓/止损/"已经投了"）
- 过度自信的断言（"我肯定""100% 确定""必然"）
- 从众判断（"大家都这样做""所有人都在买"）
- 直觉先行（"我感觉""说不清但就是觉得"）
- 复盘归因（"运气不好""环境不行""早就知道会这样"）
- 论证审查（发现自己在"两边都有道理"或滑坡推演）

### ❌ 不适合触发
- 纯事实查询（版本号/日期/定义）
- 代码报错/调试
- 创意娱乐（写故事/讲笑话）
- 无偏误信号的普通提问——按常规回答，不强制检查

## 方法论来源与证据强度

39 个偏误逐条标注证据等级，统计如下——这是本库敢于公开自检的原因：

| 标注 | 数量 | 含义 |
|---|---|---|
| 📊 学术共识 | 37 | 对照实验可复现的教科书级结论（Kahneman、Thaler、Cialdini 等） |
| 💡 经验总结 | 2 | #22 道德许可、#28 虚拟认同——practitioner 启发式，实验证据较弱，使用时降权 |

偏误库的证据基础显著强于一般"思维模型"内容：偏误研究是对照实验密集领域，绝大多数条目有直接实验范式支撑（如锚定的经典"转盘实验"、可得性的"字母频率实验"）。

- Daniel Kahneman《思考，快与慢》——系统1/系统2、锚定、损失厌恶、框架效应
- Max Bazerman & Don Moore《Judgment in Managerial Decision Making》——过度自信、谈判偏误
- Annie Duke《对赌》——决策与结果分离、事前验尸
- Robert Cialdini《影响力》——从众、权威、承诺一致

## 设计决策：几个"为什么不做得更激进"的回答

| 你可能觉得"不够好"的地方 | 为什么不那样做 |
|---|---|
| 只在检测到偏误信号时才介入，不做全程检查 | 对"Python 版本是多少"启动纠偏协议是工具滥用。触发词 + 8 类隐式结构双通道，保证"该出现时一定出现，不该出现时零打扰" |
| 纠偏句式强制"有没有可能……"，不说"你错了" | 对抗式指出偏差会触发防御反应——被纠正的人记住的是"被否定"，不是"偏差本身"。温和是对效果的工程考量，不是礼貌装饰 |
| L0/L1 不生成决策日志 | 日志的价值在信噪比。事无巨细的记录 30 天后没人复盘，等于没有 |
| 内置"文化适配"层，有些疑似偏误不纠 | 从众/权威偏误的经典实验都以个体主义文化为参照系。听长辈意见、讲面子在集体主义语境里是理性策略——强行纠偏是系统性误诊 |
| "纠偏本身是否在犯偏差"要元层自检 | 了解偏误带来的"我已经免疫"感，本身就是道德许可偏差。不设这一层，工具会把使用者变成最自信的错者 |

## 局限性：说清楚它做不到什么

- **它依赖你的原话作为信号源**。偏误藏在表述里——如果你把"我想要 X 所以找理由 Y"转述成纯问题"该选 Y 吗"，隐式结构通道可能漏检。复述时保留你的推理过程，检出率更高。
- **偏误的"有无"不等于"大小"**。协议会提示代价不对称，但精确量化某个偏误在你决策里的权重，仍要靠决策日志的 30 天后对账。
- **纠偏建议同样可能被过度自信执行**。这就是步骤 4 对抗审查和诚实声明存在的原因——它公开自己最不确定的部分，而不是假装全知。
- **不是诊断工具**。"你可能有确认偏误"是就事论事的推理检查，不是对任何人认知能力的临床判断。
- **入口成本提醒**：本 skill 的 description 常驻上下文约 280 token（触发判据必须常驻才能识别触发），SKILL.md 全文约 7.8K token 仅在触发后加载。介意上下文预算的话，单装姊妹 thinking-models（内置 39 偏误精简卡）是更轻的替代。

## 5 分钟自测：不信介绍，就测这三条

装好后依次跑三句话，每条对应一个核心承诺：

| 你输入 | 验证什么 | 通过标准 |
|---|---|---|
| "明天天气怎么样" | 零打扰承诺 | 正常回答，完全无偏误检查痕迹 |
| "大家都转 AI 赛道了，我肯定也该转，不然就晚了" | 双通道识别 | 同时点破从众（显性）+ 稀缺焦虑/基础概率忽视（隐式），且用"有没有可能"句式 |
| "帮我复盘上季度的投资，虽然亏了我认为是市场问题" | 归因审计 + 日志 | 指出自我服务偏差的双向归因检验，L2 以上生成决策日志条目 |

三条都过，它才配得上本页的宣传。过不了，来开 issue——这比 README 写得多好都重要。

## 常见问题

**Q：39 个偏误会不会让我变成"什么都能扣帽子"的人？**
会，如果不设防。所以协议内置防滥用清单（如"确认偏误 ≠ 象征性找反例"）和元层自检（#22 道德许可专门防这个）。组合规则也限制 ≤3 个偏差、至少 1 个隐式——不许名词轰炸。

**Q：和 thinking-models 是什么关系，装一个够吗？**
BC 管"哪里会出错"（信号驱动被动触发），TM 管"怎么做更好"（主动分级分析）。单装 BC：深度分析的模型支撑靠内置第一性原理+对抗审查兜底；单装 TM：偏误检查降级为精简卡。组合编号互通（沉没成本 = BC#29 = TM#1），推荐同装。

**Q：为什么决策日志只给 30 天复盘？**
30 天是可验证结果开始出现的最低窗口（周太短、季太长易遗忘），且与"事前写预测"配合刚好覆盖一个完整决策-反馈周期。周期可自定，间隔的价值在"有真实结果可对照"。

**Q：它会不会把简单问题想复杂？**
分级介入正是防这个：L0 一句话增值、L1 一个提醒点缀、L2-L3 才展开六步。你说"直接答"时退出机制立刻生效。

**Q：Claude Code 之外怎么用？**
Cursor/Codex/Cline/Continue 复制 `AGENTS.md` 到项目根目录——协议同源，格式适配。
